# 🌍 World Countries Data Explorer

A modern, interactive web application that provides comprehensive information about countries worldwide. Built with React and Material UI, this explorer fetches real-time data from the REST Countries API.

## ✨ Features

- **🔍 Search Functionality:** Quickly find any country by name.
- **📂 Regional Filtering:** Browse countries by continent (Africa, Americas, Asia, Europe, Oceania).
- **🌓 Dark Mode:** Sleek theme toggle for better visibility in any lighting.
- **📱 Fully Responsive:** Optimized for mobile, tablet, and desktop viewing.
- **⚡ Real-time Data:** Fetches up-to-date information including population, capital, flags, and more.

## 🛠️ Tech Stack

- **Frontend:** [React](https://reactjs.org/)
- **UI Components:** [Material UI (MUI)](https://mui.com/)
- **API Requests:** [Axios](https://axios-http.com/)
- **Icons:** [MUI Icons](https://mui.com/material-ui/material-icons/)

## 🚀 Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/avinashthakur100/countriesdata.git
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm start
   ```

Open [http://localhost:3000](http://localhost:3000) to view it in your browser.
